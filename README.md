# ZIYO SHOP — Luxury Women's Fashion

Вебсайти статикӣ барои мағозаи либосҳои занона. Барои GitHub Pages омода шудааст ва сервер ё базаи маълумот талаб намекунад.

## Имкониятҳо

- Тарҳи Premium бо сиёҳ, тиллоӣ ва беж
- Мутобиқ ба телефон, планшет ва компютер
- Ҷустуҷӯ, категорияҳо ва тартибдиҳии маҳсулот
- Дӯстдоштаҳо
- Сабади харид бо нигоҳдорӣ дар браузер
- Интихоби андоза ва ранг
- Омода кардани фармоиш ва фиристодан тавассути WhatsApp
- GitHub Actions барои санҷиши одӣ ҳангоми push

## 1. Рақами WhatsApp-ро танзим кунед

Файли `assets/js/app.js`-ро кушоед ва ин сатрро пайдо кунед:

```js
whatsappNumber: "992XXXXXXXXX",
```

`992XXXXXXXXX`-ро бо рақами воқеии WhatsApp-и мағоза иваз кунед. Рақам бояд танҳо рақамҳо дошта бошад: рамзи кишвар ва рақам, бе `+`, фосила ё тире.

Мисол барои шакл: `992900000000` — ин танҳо мисол аст, рақами воқеӣ нест.

## 2. Маҳсулотро иваз кунед

Дар оғози `assets/js/app.js`, массиви `PRODUCTS`-ро пайдо кунед. Барои ҳар маҳсулот ин майдонҳо мавҷуданд:

- `id`: рақами нодири маҳсулот
- `name`: номи маҳсулот
- `category`: `Либос`, `Костюм`, `Блузка` ё `Аксессуар`
- `price`: нарх бо сомонӣ
- `oldPrice`: нархи пешина (ихтиёрӣ)
- `tag`: нишони маҳсулот (ихтиёрӣ)
- `image`: ID-и акси Unsplash

Аксҳои намунавӣ аз интернет гирифта мешаванд. Барои аксҳои худ URL-и расмро дар майдони `image` мувофиқ кунед ё файлҳоро дар `assets/images/` гузошта, суроғаҳои маҳаллиро истифода баред.

## 3. Нашр тавассути GitHub Pages

1. Дар GitHub репозитории нав созед, масалан `ziyo-shop`.
2. Ҳамаи файлҳои ZIP-ро ба репозиторий гузоред. Файли `index.html` бояд дар решаи репозиторий бошад.
3. Ба **Settings → Pages** дароед.
4. Дар **Build and deployment** варианти **GitHub Actions**-ро интихоб кунед.
5. Ба бахши **Actions** дароед ва анҷоми workflow-и `Deploy ZIYO SHOP to GitHub Pages`-ро интизор шавед.
6. Пас аз муваффақ шудани workflow, GitHub Pages URL-и сайтро нишон медиҳад.

## Муҳим

Ин лоиҳа мағозаи статикӣ аст. Фармоиш дар WhatsApp кушода мешавад, вале худи сомона фармоишро ба сервер сабт намекунад. Пардохти онлайн, идоракунии анбор ва панели маъмурӣ дохил нестанд. Пеш аз истифода нархҳо, суратҳо, андозаҳо, рақами WhatsApp ва шартҳои расониданро санҷед.
